# DRFC-0027: Wire Protocol

Status: Canonical

## Required Fields
- version
- type
- session
- node
- timestamp
- signature

## Compatibility
- Unknown fields MUST be ignored.
- Missing required fields MUST reject the message.
- Major version mismatch MUST trigger compatibility negotiation.

## Example
{
  "version":"2.0",
  "type":"handshake",
  "session":"uuid",
  "node":"node-A"
}

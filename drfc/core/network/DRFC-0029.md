# DRFC-0029: Version Negotiation

Status: Canonical

## Purpose
Define how two Dharma nodes negotiate protocol versions.

## Rules
- Every handshake MUST advertise a major and minor version.
- Different minor versions SHOULD remain compatible.
- Major version mismatch MUST fail negotiation unless a compatible profile exists.

## Example
Node A: 2.1
Node B: 2.0
Result: Protocol 2.0 compatibility mode.

# DRFC-0045: Protocol Registry

Status: Draft

## Purpose

Define canonical Dharma message type assignments.

## Registry

- HELLO = 0x01
- ACCEPT = 0x02
- ROUTE_ANNOUNCEMENT = 0x03
- TRUST_PROPOSAL = 0x04
- SESSION_RESUME = 0x05
- DCP_MESSAGE = 0x06

Future DRFCs MUST allocate new message types through this registry.

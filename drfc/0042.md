# DRFC-0042: Wire Protocol v1

Status: Draft

## Header

- Version: 1 byte
- Message Type: 1 byte
- Payload Length: 2 bytes (big-endian)
- Payload: UTF-8 JSON

## Versioning

Nodes MUST reject unsupported protocol versions.

## Compatibility

Wire Protocol v1 is the canonical transport format for Dharma messages.

# Dharma Protocol (dharma-core)

**Founder:** Paresh Somani

Dharma is an open authority protocol designed to preserve legitimate authority across humans, AI agents, organizations, APIs, and future autonomous systems.

## Principle 0

> Capability does not constitute authority.

## Quick Start

```bash
git clone https://github.com/<username>/dharma-core.git
cd dharma-core
pip install -r requirements.txt
pytest
```

Run the demo:

```bash
python examples/demo.py
```

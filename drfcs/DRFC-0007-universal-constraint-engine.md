# DRFC-0007

Title: Universal Constraint Engine (UCE)

Status: Draft

Version: 0.1

Author: Dharma Core

Date: 2026-09-15

## Abstract

The Universal Constraint Engine defines how Dharma-compatible systems evaluate actions against immutable constraints before execution.

## Core Principles

- Constraints precede optimization.
- Safety precedes efficiency.
- Local and global constraints are composable.
- Every decision must be explainable.
